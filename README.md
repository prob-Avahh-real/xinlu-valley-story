# 芯麓谷物语 (Xinlu Grain Valley)

A pixel-art farming simulation RPG for mobile, inspired by Stardew Valley.

## Tech Stack

- **Framework:** Flutter + Dart
- **Game Engine:** Flame + Bonfire
- **State Management:** Provider
- **Persistence:** Hive, SharedPreferences
- **Platform:** iOS / macOS / Android

## Project Structure

```
lib/
  core/     — Shared utilities
  data/     — Save/load, game data
  game/     — Player, NPCs, map
  systems/  — Farming, inventory, crafting, relationship, time
  ui/       — Menu, shop, inventory, save screens
```
